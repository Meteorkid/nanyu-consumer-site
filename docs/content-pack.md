# 消费者入口内容包（首版）

## 1. 品牌内容

- 品牌一句话（中文）：做年轻人买得起的好玉
- 品牌一句话（英文）：Affordable jade for young global consumers
- 品牌故事（100字）：玉汝于成以中国玉文化为底色，结合现代设计与跨境电商能力，打造更年轻、可日常佩戴的玉饰品牌。
- 品牌故事（300字）：用于“关于品牌”页面与媒体介绍，建议补充团队、落地城市、阶段成果与社会价值。

## 2. 商品内容字段（每个 SKU 必填）

- 基础信息：`slug`、商品名、价格、库存、类目
- 规格信息：材质、尺寸、重量、颜色
- 卖点文案：3 条（短句，避免空泛形容词）
- 适用场景：送礼 / 日常 / 收藏
- 寓意标签：平安 / 事业 / 爱情 / 健康
- 物流信息：发货地、时效区间、运费规则
- 售后口径：7天退货/15天换货是否适用

## 3. 内容中心首批选题（建议 12 篇）

### 搭配教程（4篇）
- 通勤穿搭与玉饰搭配
- 学生党预算内玉饰推荐
- 送礼场景搭配模板
- 夏季轻量佩戴指南

### 用户故事（4篇）
- 海外消费者首次购买故事
- 本地手工合作故事
- 从原料到成品的链路故事
- 礼物场景真实反馈

### 选购知识（4篇）
- 新手如何看尺寸与重量
- 真伪溯源怎么看
- 日常保养常见误区
- 不同价位段怎么选

## 4. 售后与合规文案

- 退换政策最终版（法务确认）
- 跨境物流说明（按区域）
- 客服时效说明（在线时间与响应承诺）
- 公司主体信息（可公开版）
- 商标、证书、溯源说明（可核验版）
