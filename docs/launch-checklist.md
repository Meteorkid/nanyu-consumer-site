# 消费者入口上线清单（MVP）

## 1. 发布前检查

- [ ] 商品数据完整（名称、价格、库存、规格、图片）
- [ ] 售后政策使用最终法务版本
- [ ] 多语言核心页面（首页/商品页/售后页）完成校对
- [ ] 关键埋点可见（浏览器 `dataLayer` 与 GA4 实时事件）
- [ ] 移动端关键页面可用

## 2. 技术验收

- [ ] `npm run lint` 通过
- [ ] `npm run build` 通过
- [ ] 首屏加载速度可接受（目标 LCP <= 2.5s）
- [ ] 图片无明显拉伸和加载失败

## 3. 运营验收

- [ ] 首批 12 篇内容已上线
- [ ] 每篇内容绑定 2-4 个商品链接
- [ ] 客服入口可触达（微信/邮箱/表单）
- [ ] 常见问题（FAQ）覆盖退换、物流、保养、真伪

## 4. 上线后 2 周观察指标

- 首页 -> 商品页点击率
- 商品页 -> 咨询/下单点击率
- 内容页 -> 商品页点击率
- 退款率与售后咨询占比
